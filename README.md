# Ordex — платформа для замовлень та звітів

Десктоп-програма на Python/Tkinter для ведення прайс-листа, бази клієнтів
та формування заявок на покупку у форматі Excel.

## Запуск

1. Встановіть Python 3.9+ (https://www.python.org/downloads/)
2. Встановіть потрібні бібліотеки:
       pip install openpyxl matplotlib requests
3. Запустіть програму:
       python3 main.py

При першому запуску програма сама створить файл бази даних order_app.db
у цій же папці.

## Як користуватись

### 1. Завантаження прайс-листа
Меню "Файл" -> "Завантажити прайс-лист..." -> виберіть Excel-файл.
Програма сама намагається розпізнати колонки за заголовками:
код/артикул, назва/найменування, ціна, вага, од.вим.
Програма запитає дату, з якої діють нові ціни (можна залишити порожньо —
тоді ціни діють з сьогодні). Стару історію цін програма не стирає:
можна в будь-який момент довантажити оновлений прайс, і заявки надалі
формуватимуться за останніми діючими цінами.

Верхня панель програми має три пункти: **Файл** (завантаження прайс-листа),
**Налаштування** (телефони відправника, API-ключі перевізників) і
**Звіти** (усі звіти нижче). У бічному меню зліва — лише "Нова заявка"
і "Історія заявок".

### 2. Телефони відправника
Меню "Налаштування" -> "Телефони відправника..." — тут можна додати
відповідність "спосіб оплати -> номер телефону 
-> ім'я відправника" (наприклад "рр ІОМ" -> "096 356 65 18" -> "Мельник
Олег Іванович"). При виборі способу оплати в заявці телефон і ім'я
відправника (для ТТН) підставляються автоматично, з можливістю ручного
редагування.

### 3. Формування заявки (вкладка "Нова заявка")
Екран розділено на дві колонки: зліва — дані відправника (номер заявки,
відповідальний, спосіб оплати, телефон і ім'я відправника), справа —
покупець та одержувач.

- Вкажіть номер заявки вручну, дата ставиться автоматично.
- В полі "Покупець" почніть вводити прізвище — якщо клієнт вже є в базі,
  програма підкаже і підтягне його дані (адресу, телефон, область, місто,
  перевізника). Якщо клієнта ще немає — просто впишіть ПІБ, він
  збережеться в базу після формування заявки.
- Поле "Телефон одержувача" також працює як пошук: почніть вводити цифри
  телефону (в будь-якому форматі — з пробілами, дужками, тире) — якщо
  цьому номеру вже колись формувалась заявка, програма підкаже клієнта і
  підтягне всі його дані (ім'я, адресу, область, місто, відділення) так
  само, як і пошук за іменем.
- Область і місто одержувача вводяться з підказками (почніть друкувати
  перші літери). Список міст поповнюється по мірі використання програми.
- У блоці "Додати товар" почніть вводити назву товару — програма підтягне
  код, ціну та вагу з прайс-листа. Впишіть кількість і натисніть "+" —
  рядок додасться в таблицю, суму і вагу програма порахує сама.
- Кнопка "Сформувати заявку" створює Excel-файл у форматі зразка
  (папка orders/), зберігає заявку та дані клієнта в базу для подальшого
  використання.

### 4. Доставка: на відділення / адресна / самовивіз
При виборі перевізника (Нова Пошта, САТ, Делівері) можна вказати тип
доставки — "На відділення" (поле № відділення) або "Адресна доставка"
(поля вулиця, будинок, квартира). При виборі "Самовивіз" ці поля
неактивні, бо доставка не потрібна.

### 5. Історія заявок
Вкладка "Історія заявок" показує всі раніше сформовані заявки, включно
з номером ТТН (якщо його було створено автоматично).

### 6. Звіти та аналітика
У меню "Звіти" (верхня панель) — набір звітів за вибраний період
(дата з / дата по):
- **Зведення** — кількість заявок, загальна сума, вага, середній чек
- **Товари** — що купують найбільше, з графіком топ-10
- **Клієнти** — хто купує найбільше
- **Географія** — звідки/куди найбільше замовлень
- **Перевізники** — розподіл по перевізниках

Кожен звіт можна зберегти в Excel-файл або скопіювати в буфер обміну
одним натисканням — скопійовану таблицю можна одразу вставити в Excel
(Ctrl+V).

### 7. Автоматичне створення ТТН (накладних)
Меню "Налаштування" -> "API-ключі перевізників..." — тут для кожного
перевізника можна зберегти API-ключ. **Для Нової Пошти** додатково
потрібні: місто та номер відділення відправника, а також Ref
контрагента-відправника і Ref контактної особи відправника — це ваші
ідентифікатори в системі Нової Пошти, їх можна знайти в особистому
кабінеті на my.novaposhta.ua (розділ "Контрагенти") або отримати у
службі підтримки для вашого бізнес-акаунту.

Коли API-ключ і всі дані відправника заповнені, на формі заявки
з'являється прапорець "Створити ТТН автоматично при формуванні заявки"
(увімкнений за замовчуванням). При натисканні "Сформувати заявку"
програма сама зв'яжеться з сервером Нової Пошти, створить накладну і
одразу впише номер ТТН у заявку — і на екран, і в сам Excel-файл.

Якщо щось не вдалось (немає ключа, немає з'єднання, невірні дані) —
заявка все одно сформується як звичайно, просто без номера ТТН, а
програма покаже зрозумілу причину помилки. Створити накладну вручну
на сайті перевізника можна в будь-який момент пізніше.

**Обмеження:** автоматичне ТТН зараз підтримує лише Нову Пошту і лише
доставку "На відділення". Для САТ і Делівері інтеграція поки не
підключена — програма чесно про це повідомляє замість того, щоб
імітувати роботу. Якщо у вас є технічна документація API цих
перевізників — інтеграцію можна додати так само, як для Нової Пошти.

Логіка звернень до API написана за офіційною специфікацією Нової Пошти
(v2.0, JSON), але жодного реального виклику до їхніх серверів під час
розробки не виконувалось (немає доступу до зовнішньої мережі й
реального ключа в середовищі розробки) — перший запуск варто зробити
на тестовій заявці з невеликою сумою.

### 8. Відстеження статусу доставки та сповіщення
Програма сама стежить за заявками з ТТН, які ще не позначені як
доставлені:
- при кожному запуску програми — одразу перевіряє їхній статус;
- далі — повторно, з інтервалом, який можна змінити в меню
  "Налаштування" -> "Сповіщення та відстеження..." (за замовчуванням
  30 хвилин). Перевірка працює, поки програма відкрита, навіть якщо
  вікно згорнуте — окремого фонового сервісу Windows для цього не
  потрібно.

Коли статус заявки змінюється, знизу справа екрана (біля годинника)
з'являється спливаюче повідомлення, наприклад:
*"Відправлення для Вовк Олександр Миколайович м. Тернопіль отримано."*
Повідомлення залишається на екрані, поки ви самі не натиснете
хрестик — воно не зникає автоматично. Показ таких повідомлень можна
вимкнути в тому ж діалозі налаштувань.

У вкладці "Історія заявок" з'явилась колонка "Статус доставки", а
рядки підсвічуються кольором: зелений — доставлено, жовтий — у дорозі,
червоний — не вдалось створити ТТН. Кнопка "Перевірити статуси зараз"
запускає перевірку вручну, не чекаючи наступного автоматичного циклу.

## Структура файлів
- main.py — головне вікно програми
- db.py — робота з базою даних (SQLite, файл order_app.db)
- price_import.py — читання прайс-листа з Excel
- order_export.py — генерація Excel-файлу заявки
- reports.py — звіти, експорт в Excel, копіювання в буфер
- carriers.py — інтеграція з API перевізників (створення ТТН)
- autocomplete.py — поле вводу з підказками
- ukraine_regions.py — довідник областей та міст України
- assets/ — значок програми (ordex_icon.ico, ordex_icon_256.png)
- orders/ — сюди зберігаються згенеровані файли заявок

## Що ще варто буде донастроїти
- Додати реальні варіанти "спосіб оплати -> телефон" (зараз є лише
  приклад "рр ІОМ").
- Перевірити автоматичне створення ТТН на реальному API-ключі Нової
  Пошти (не тестувалось наживо) — і повідомити про будь-які помилки,
  щоб їх виправити.
- За потреби — розширити список перевізників або довідник міст.
- Підключити API САТ і Делівері, коли з'явиться їхня документація.
